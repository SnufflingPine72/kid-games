# Kid Games

Four small, offline-friendly games for kids, made for tablets.

| Game | What you do |
|---|---|
| **Pollen Quilt** | Send bees with colored pollen to stitch a pixel-art quilt. Has an Easy mode. |
| **Pollen Quilt Math** | Solve simple addition (up to 20) to stitch each picture. |
| **Spotty's Maze Munch** | Guide Spotty the ladybug through a wiggling maze to munch every mini bug. |
| **Hoppity Lanes** | Hop across roads, rails and rivers, collect coins and unlock 20 characters. Lincoln mode is the gentle, no-scroll version. |

## Play on an iPad

1. Open the site in **Safari** and tap a game.
2. Tap **Share → Add to Home Screen → Add**.
3. Open the game from its new icon. After the first visit it works without internet.

Each game folder has a service worker that keeps all of its files on the device, so it plays offline and picks up updates the next time it is opened online.
